Install ShotClock

Install ShotClock to your home screen for a full-screen, app-like experience — no browser chrome eating the screen. State stays where it is; nothing else changes.

iOS doesn't let apps install themselves — but the Add-to-Home-Screen button is in Safari's Share menu. Three taps:

1. Tap Share
2. Tap Add to Home Screen
3. Tap Add

Your browser hasn't offered me a one-tap install button yet (sometimes Chrome needs a couple of visits to "warm up," or the app is already installed). You can install manually:

  1. Tap the ⋮ menu in the top-right of your browser.
  2. Look for Install app, Add to Home screen, or Open ShotClock (if it's already installed).
  3. Confirm.
